01 // THE CHALLENGE

Why Campus Printing Needs an Engineering Reset.

Every semester, tens of thousands of students and faculty experience identical bottlenecks at campus xerox counters. SmartPrint addresses the systemic flaws in traditional walk-in printing.

01 / PRIVACY & SECURITY RISKS

The Flash Drive & Chat Vulnerability

Handing personal USB drives to public counter PCs exposes personal devices to malware and rootkits. Forwarding private lab records, ID proofs, and resumes through personal WhatsApp chats creates an unmanaged data trail on shop computers.

02 / PEAK-HOUR BOTTLENECKS

Between-Class Queue Delays

During the 15-minute rush before morning lectures or lab submissions, 30+ students crowd a single counter operator. Manual file browsing, page opening, and paper alignment create extreme frustration and missed deadlines.

03 / CONFIGURATION ERRORS

Manual Miscommunication & Paper Waste

Ambiguous spoken instructions ("print pages 3 to 14, double-sided, except page 8") frequently lead to misprinted reams, squandered toner, and tense pricing disputes between students and shop owners.

04 / COUNTER OVERLOAD

Operator Fatigue & Cash Chaos

Shop owners spend over 65% of their working day manually opening files, verifying individual UPI payment screenshots on personal phones, and calculating loose change rather than monitoring print hardware.

The SmartPrint Approach

A decoupled system architecture where customers configure documents, inspect authoritative quotes, and submit orders from their personal mobile browsers. Orders flow directly into an automated local spooler on the shop counter PC.

✓ Zero USB flash drives or chat forwards
✓ Cryptographically verified payment & quotes
✓ 24-Hour automated document deletion
✓ Native spooler driver integration
02 // SYSTEM WORKFLOW

Frictionless End-to-End Execution.

From mobile upload to physical collection tray in five deterministic steps. No apps to install from an app store, no shared drivers to configure, and zero guesswork.

01

Select & Upload

User selects their campus station (e.g. AUCE Printing Centre) and drops their PDF. Client-side WebAssembly inspects page counts and geometry instantly.

React 18 + PDF.js
02

Configure & Quote

Choose B&W or Color, copies, page ranges (`1-5, 8`), duplex with discount, paper GSM, and binding options. Server validates inputs and returns authoritative pricing.

Edge Functions • RLS
03

Pay & Dispatch

Checkout seamlessly via UPI QR (Cashfree) or select Walk-in Counter Cash. An instant public tracking reference (`#SP-XXXXXX`) is generated.

Cashfree PG + Idempotency
04

Autonomous Spool

Counter print agent claims the job atomically, verifies SHA-256 checksum integrity, spools to the printer driver, and updates the customer's live tracking status.

Python 3.11 + winspool.drv
03 // CORE CAPABILITIES

Engineered for Both Sides of the Counter.

Built to deliver peace of mind to students and staff while giving xerox operators an enterprise-grade command dashboard.

📱

Zero-Install Mobile PWA

Runs directly inside Safari, Chrome, or Firefox. No bulky mobile app downloads, zero app store friction, and instant QR-scan launch at station entry.

🔒

Privacy by Design

Uploaded documents are stored in private encrypted storage buckets, accessed exclusively via short-lived signed URLs, and automatically deleted within 24 hours.

⚡

Authoritative Pricing Matrix

Zero client trust. Server backend strictly re-validates all page ranges, duplex rules, and pricing tiers to ensure mathematical billing accuracy.

📊

Counter Spool Console

Dedicated web and Electron dashboard for shop owners showing today's revenue, completed volume, active queues, and one-click reprint controls.

🖥️

Durable Local Print Agent

Lightweight daemon running on counter Windows or Linux mini-PCs. Uses atomic disk journaling (`os.fsync`) to prevent accidental double-printing after power cuts.

🔑

Cryptographic Shop Pairing

Pair counter PCs in seconds using 15-minute expiring pairing codes. Scoped device tokens are hashed with SHA-256 with zero database secret leakage.

01 / Zero Client Trust

All page calculations, pricing proofs, and authorization are verified strictly by the server. The client cannot forge payment status.

02 / Atomic Job Leasing

Jobs are claimed by print agents via atomic `FOR UPDATE SKIP LOCKED` database transactions, preventing duplicate dispatches.

03 / Durable Local Journal

All spool transitions are synced to local disk with `os.fsync`. Interrupted jobs recover to `needs_review` without blind re-prints.

04 / Credential Isolation

Agents authenticate with short-lived scoped device bearer tokens. Zero database root credentials or payment secrets ever reach the kiosk.
